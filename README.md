# Civ4のMODのBlogのソース

This is a website in Japanese (but you can use a translator, Google translate for example maybe, to translate it to the language of your choice, for example english (Chromium based browsers for example support right clicking on the page then translate to your language, Firefox too but as of now you have to go to the URL bar at the top for that function)).

You can browse the website [here](https://gforestshade.github.io/kujira/)

These are the topics covered:
- Python
- XML
- C++: instructions on how to compile CvGameCoreDll.dll (2018-05)
- General information (hopefully i got this one correctly while writing this readme doc)
- MMD to CIV4
